# Matrice des responsabilites des agents BMAD

| Agent | Responsabilite | Livrables |
| --- | --- | --- |
| Serigne | Orchestration BMAD, arbitrage, continuite | Decision d'orchestration, cadrage, statut de cycle |
| Mamadou | Analyse, personas, besoins, contexte | Notes d'analyse, personas, risques, recommandations |
| Babacar | Epics, stories, backlog, priorisation | PRD, backlog, epics, priorites |
| Aïssatou | Wireframes, parcours utilisateur, accessibilite, experience utilisateur | UX research, wireframes, parcours, recommandations WCAG |
| Cheikh | Architecture, ADR, contraintes techniques | Architecture cible, ADR, contraintes et impacts |
| Ibrahima | Specifications, criteres d'acceptation, contrats d'implementation | SPEC, criteres d'acceptation, contrats fonctionnels |
| Ousmane | Implementation, tests, integration | Code, tests, resultats de validation, commits |
| Fatou | Validation, qualite, regression | Rapport QA, tests de regression, anomalies |
| Moustapha | Revue finale, validation du scope, revue d'architecture | Rapport de revue, decision de readiness |
| Khadim | Vectorisation, catalogage, indexation documentaire | Catalogue, relations, metadonnees vectorisables |
